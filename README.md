🚀 HireReadyAI

HireReadyAI is an AI-powered interview preparation and assessment platform built using the MERN stack and powered by the Gemini AI API. It helps candidates analyze their resumes, identify skill gaps, generate personalized interview questions, and practice realistic AI-driven mock interviews with real-time feedback.

✨ Features
🔐 Authentication System
Secure JWT-based authentication
User registration and login
Protected routes and session management
📄 AI Resume Analyzer

Users can input:

Resume
Self-description
Job description

The system analyzes the input using AI and generates:

Resume score out of 100
Technical interview questions
Behavioral interview questions
Intent behind each question
Skill gap analysis
Personalized improvement suggestions
🎤 AI Mock Interview (Real-Time)
User selects:
Job role
Difficulty level (Easy / Medium / Hard)

The AI interviewer:

Conducts a realistic interview session
Asks role-based questions
Collects answers via microphone
Uses camera for live interview simulation
Evaluates responses in real-time
📊 AI Feedback & Report Generation

After the interview, HireReadyAI provides:

Detailed performance analysis
Strengths and weaknesses
Communication feedback
Technical evaluation
Improvement recommendations
Overall interview score

Users can also:

Download a PDF interview report
